# 现场数据工具的合成示例

两个 CSV 均为确定性生成的示例，不来自样机、仪器或 HIL 实测。运行入口见[现场数据说明](../../docs/field-data.md)。

- capture.csv：1001 点，1ms 间隔，时间列比共同示例时间晚 10ms。包含请求 2250rpm、编码 2240rpm、合成模型转速、三相正弦电流、示例反馈电压和六路采样逻辑状态。
- lin.csv：每 20ms 产生控制/状态帧样例，采用已归档 LDF 的编码和校验规则；tx/rx 仅为合成标签，未发生硬件发送。
- 模型转速在 0～0.1s 升到 2240rpm，正常段叠加幅值 2rpm 的正弦变化，0.6s 显式停止事件后线性降速，在 0.8s 到零。电流峰值约 1.2A，反馈电压为独立示例波形；这些曲线不作为真实反馈模型或板卡规格。
- 两个来源显式关联到 demo 时间组，各声明 0.25ms 的示例误差。示例门极状态仅用于检查文件与绘图，不表示实际 PWM 采样能力。

[通过清单](../../configs/field_demo_pass.json) 使用 3rpm、1.3A、0.25s 停止期限与 0.1s 保持时长；[失败清单](../../configs/field_demo_fail.json) 分别使用 0.5rpm、0.9A、0.1s 停止期限。两者的 sample performance 均保持未评估。精确结果和复核以实际新建的结果包为准。
