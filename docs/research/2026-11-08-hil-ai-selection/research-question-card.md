# 两项任务的应用验证卡

读者：组织原型比较的算法与实验人员。用途：固定问题、增益假设和改变选择的条件；与 [主方案](technical-selection.md) 及 [比较协议](experiment-protocol.md) 一起使用。

## A：提高有效覆盖与失效发现能力

| 项目 | 内容 |
|---|---|
| 问题/类型 | 相同需求、有效场景范围和预算下，结构化生成＋组合/序列覆盖＋搜索能否比人工/简单采样发现更多有价值的失效？应用验证 |
| 假设 | 检索规约降低人工修订；组合生成补齐交互；自适应搜索只在部分昂贵、有区分度的边界任务上有收益 |
| 当前证据 | PICT/PSY-TaLiRo 官方接口，项目电机参数和事件支持；ER-20261108-generation-08、project-13 |
| 缺失 | 当前版本动态复验、多因素可执行映射、至少两类 L2 需求的比较、真实板卡迁移 |
| 支持结果 | 有效覆盖/语义或独立反例收益明确，重复/已知失败分列，调用与墙钟成本可接受 |
| 证伪/改变选择 | 增益只来自重复已知失败；人工/随机同样好；生成修订时间反而增加；BO 成本更高 |
| 最小下一步 | 冻结两类电机需求和因素表；少量复验测成本；独立预试判断边界难度后运行 A1–A3 |
| 决定 | 开展小规模应用比较；采用规约/回调架构，优化器待选 |

## B：提高分析深度、异常发现与诊断效果

| 项目 | 内容 |
|---|---|
| 问题/类型 | 哪种方法组合能从电机 HIL 多源数据提取更有用特征，并在未见工况下更准确发现异常、区分故障和定位环节？应用验证 |
| 假设 B1 | 事件/时频特征与动态模型能量化单个稳态判据遗漏的反转、振荡和响应差异 |
| 假设 B2 | 条件化基线、TimeRCD 或通用表示在不同异常类型上有互补收益；不能预先指定唯一赢家 |
| 假设 B3 | MantisV2 或 TS2Vec 在相同标签预算下可能改善故障识别/跨工况表现；MiniRocket 与物理特征是必须击败的基线 |
| 假设 B4 | 多源残差/参照和针对性复验能区分相似表象；AERCA 在合适假设下可能提高源头排名 |
| 当前证据 | ER-20261108-mantis-01 至 signal-sysid-07；项目有模型动态记录与多通道入口，尚无这些方法的独立诊断成绩 |
| 缺失 | 可识别故障机制、标签与混淆任务对；物理残差所需观测点；工况留出集；权重本机运行与成本 |
| 支持结果 | B1–B5 对应特征误差、事件召回、宏 F1、部件定位或复验成本有稳定改善；资源适合应用 |
| 证伪/改变选择 | 表示模型未超过基线；正常动态大量误报；分类仅记住工况/注入痕迹；定位只选最大症状；复验无法缩小原因集合 |
| 最小下一步 | 用电机复验数据开展 B1 和条件化 B2，同时实现两类闭环故障及独立探针，为 MiniRocket/MantisV2 的 B3 对比准备数据 |
| 决定 | 分任务建设分析能力；无标签不妨碍 B1/B2，诊断缺数据则安排采集/机制扩展，不把任务缩成报告系统 |

共同质量门槛：数据适合目标尺度、评价单元独立、数值可核对、结论范围明确。它们是采用必要条件，不能单独证明分析价值。
