对应材料：[完整方案](../2026-11-11-hil-ai-selection/technical-selection.md)、[讨论稿](../2026-11-11-hil-ai-selection/discussion-brief.md)、[工程与实验参考](../2026-11-11-hil-ai-selection/implementation-reference.md)。前期来源见[2026-11-09 LLM 专题调研](../2026-11-09-llm-core-methods/research-report.md)。本文保存本轮判断；后续采用状态以完整方案为准。

## 1. 调研问题与范围

本轮要回答：当前主参考是否只提供“LLM 提案—工具执行—反馈”的一般流程？是否存在以大模型为核心、在推理、决策或训练机制上更具体的方法，可以支持两项研究任务？

检索首先扩展到优化、诊断和实验设计。在明确研究重点是大模型方法后，重点筛选 LLM 参与搜索、统计模型发现、信息获取策略学习和信号—知识对齐的论文。传统贝叶斯优化、结构诊断和主动特征获取仅作为背景线索，不作为本轮新增主路线。

代表性检索词包括：

- `LLAMBO language models Bayesian optimization ICLR 2024 method`
- `LLM scientific model discovery BoxLM automated probabilistic modeling 2024`
- `Bayesian experimental design language model agents hypothesis information gain`
- `LLM sequential experimental design information gain reinforcement learning`
- `large language model fault diagnosis causal reasoning reinforcement learning tool selection industrial time series`
- `LLM fault diagnosis signal alignment multimodal FaultGPT`

来源优先采用论文正文、会议论文集和期刊原文。对重点文献读取方法及相关评价、局限部分；未复现算法、核查全部代码或完成全领域系统综述。本轮没有运行 LLM/HIL 实验。下面分别标明原论文的方法、对本项目的推断和迁移前提。

## 2. 核心判断

当前方案主要借鉴了流程与信息组织，但原参考并非都缺少具体方法。LLM-Falsifier 具有明确优化目标和语义反馈设计；S2S-FDD 包含信号重构、残差组织、检索和多轮诊断；TraceBench 的主要作用是受控评测。把三者并列为算法主路线，会混淆方法来源与评价依据。

本轮已找到 2024 年的 LLAMBO、BoxLM 及后续大模型研究，因此不能将方法不足直接解释为“相关领域文献少”。更有用的检索方式是从核心能力出发：大模型如何选择测试、提出可计算假设、利用反证、学习查询策略，以及对齐信号和知识。本文没有统计论文数量，不作整个领域稀缺性的判断。

方法是否值得采用，主要检查四件事：LLM 输出什么对象；对象如何由独立计算或数据检验；检验结果怎样改变下一次决策；能否通过匹配条件的实验定位增益来源。模型结构、公式或训练流程的复杂程度本身不足以说明 HIL 效果。

|---|---|---|

## 4. 新增的大模型方法依据

### 4.1 LLAMBO：分环节研究大模型如何改善搜索

**直观理解：让 LLM 分别帮助决定从哪里开始、提出哪些候选，以及怎样预测候选表现。**

论文：Tennison Liu 等，*Large Language Models to Enhance Bayesian Optimization*，ICLR 2024。[会议记录](https://proceedings.iclr.cc/paper_files/paper/2024/hash/84b8d9fcb4e262fcd429544697e1e720-Abstract-Conference.html)；[方法正文](https://arxiv.org/html/2402.03921)。已读框架、初始化、代理建模、候选生成及相关评价。

原方法将问题和历史观测表达为自然语言，利用上下文学习参与贝叶斯优化的不同环节。初始化利用领域知识选点；候选采样根据历史生成有潜力的输入；代理模型预测目标值或达到目标阈值的可能性。各模块可分别研究，原实验主要围绕超参数优化。

**拟采用：** 借鉴分环节研究方式，先比较 LLM 初始工况与启发式、随机/Sobol 初始点，再比较历史反馈下的直接候选与外层模式/区域选择。初始点比较固定后续搜索，外层比较固定内层优化器，总预算匹配。通过这些替换判断收益来自初始化、后续决策还是反馈内容。

**条件与限制：** 这是向 HIL 的方法改编，不是完整 LLAMBO 复现。若采用其 LLM 代理评分模块，需评价预测误差和不确定性校准。原文明确承认通过多次采样、打乱上下文示例获得概率估计的方式包含启发式；生成结果的分散程度不能直接等同于可靠不确定性。

### 4.2 BoxLM：让原因假设成为可检验的模型

**直观理解：LLM 提出能产生预测的模型，工具用数据检验，LLM 根据偏差继续修改。**

论文：Michael Y. Li、Emily Fox、Noah Goodman，*Automated Statistical Model Discovery with Language Models*，ICML 2024。[会议记录](https://proceedings.mlr.press/v235/li24v.html)；[正文 v2](https://arxiv.org/html/2402.17879v2)。已读模型生成、拟合、批评过程及实验设置。

原方法用概率程序表示 LLM 生成的模型，由通用数值推断完成拟合和评分；将预测统计与数据之间的偏差提供给负责批评的 LLM，再以表现较好的模型和文字反馈指导下一轮提案。研究包含受限模型空间、开放模型发现，以及自然语言约束下的专家模型改进。

**拟采用：** 任务二从工程确认的有限故障机制起步，让 LLM 明确作用位置、预期响应和冲突条件，选择可检查预测的分析工具，根据数值结果修订候选。先使用正常参照、事件关系和可用物理残差；响应预测在查询相应补充结果前记录。

**条件与限制：** 受限候选和现有工具检验是本项目对 BoxLM 的适配，尚不包含其完整概率程序搜索和自动推断。原因相容性与原因唯一性分开评价；同一波形上的拟合良好不能排除其他机制。完整统计建模需要可计算的候选、参数与噪声处理及独立预测检查，投入另估。

### 4.3 BMD：将模型生成、数值评价与实验选择连接起来

**直观理解：LLM 提出不同解释，数值程序比较它们，再选择最有助于分清解释的实验。**

论文：*Bayesian Model Discovery with Language Models: Closing the Loop between Hypotheses and Experiments*，2026-10-19 预印本。[正文 v1](https://arxiv.org/html/2610.25747v1)。已读 §3 的参数推断、模型比较、联合信息增益、候选扩展及反馈消融与局限。

原方法中，LLM 提出模型形式；数值程序用序贯蒙特卡洛估计参数后验和模型证据，在有限候选池内比较和平均预测。下一实验最大化关于模型类别与参数的联合预期信息增益；数值支持程度和预测残差返回 LLM，指导候选扩展。

**拟采用：** 作为后续显式模型诊断和主动复验的候选依据。重点借鉴 LLM 提案与数值评估的分工，以及数值反馈如何改变假设生成。当前仅查询已有记录的诊断阶段，先研究 BoxLM 式预测检验。

**条件与限制：** 当前证据来自仿真科学任务，尚未在本项目的电机故障或实体 HIL 上验证。模型概率以当前有限候选池和所设先验、观测模型为条件；候选缺漏可能使其不能代表真实原因的不确定性。新实验还需要明确可操作量、合法范围及可区分响应。

### 4.4 AR-BED：用信息价值训练大模型的查询策略

**直观理解：通过奖励能减少不确定性的查询，让 LLM 学会下一步查什么。**

论文：Anita Kriz 等，*Amortizing Sequential Experimental Design in Reasoning LLMs*，2026-10-14 预印本，方法名 AR-BED。[正文 v1](https://arxiv.org/html/2610.20832v1)。已读方法 §4、生成模型与奖励定义、实验范围及多步目标讨论。

原方法让 LLM 根据历史生成推理与实验动作，使用独立于被训练策略的生成模型评估信息价值，再用 GRPO 优化多步信息奖励。其自然语言实验使用独立的较大 LLM 作为语义似然评价者；这类评价者仍有误差，不能视为真实物理模型。原验证主要包括 Twenty Questions 和向 Medi-Q 的迁移。

**拟采用：** 在查询策略成为瓶颈后，研究利用经核验的故障环境、观测模型或数据构造奖励，训练 LLM 选择更有区分作用的通道、窗口和工具。将信息奖励换成适用于 HIL 的可靠计算是待研究工作。

**条件与限制：** 需要候选—查询—观测之间可信的关系、足够训练交互及独立评测。提示 LLM “选择信息增益最大的问题”并不等同于采用该训练方法。GRPO 的训练成本、奖励误差和多步收益应单独评价，本轮不承诺立即训练。

### 4.5 DiagLLM：训练信号表示与机理知识的对应关系

**直观理解：把信号图像与故障知识共同交给模型，通过训练建立对应关系。**

论文：Jie Wang 等，*DiagLLM: multimodal reasoning with large language model for explainable bearing fault diagnosis*，Science China Information Sciences，2025，68(6)，160103。[期刊全文](https://scis.scichina.com/en/2025/160103.pdf)；[DOI](https://doi.org/10.1007/s11432-024-4333-7)。已读 §3 架构、指令数据与训练设计及实验范围。

原方法将轴承包络谱图像通过视觉编码器和投影层映射，与任务和专家知识文本共同输入 LLM；使用 LoRA 等可训练部分进行参数高效适配。研究重点是故障类别识别、有限数据和跨数据集表现。

**拟采用：** 若当前数值摘要持续遗漏有效诊断信息，再评估适合速度、电流和转矩响应的信号表示与知识配对。届时比较纯数值摘要、图像输入和训练对齐的增量效果。

**条件与限制：** 轴承包络谱的诊断依据与电机控制瞬态不同；轴承上的效果不能直接迁移。分类正确和生成解释本身不足以证明区分了本项目关注的相似故障机制。需要重新准备配对数据、控制工况差异并检验原因区分。

## 7. 后续阅读与验证顺序

1. **任务一先读 LLAMBO 的模块与消融。** 确定初始点数量、后续优化器、候选接口及总预算；先选择一个环节验证，再决定是否扩大。
2. **任务二先读 BoxLM 的模型表示和反馈内容。** 将一个已核验故障写成可计算或可检查的响应预测，确认工具能检验、冲突能影响判断；避免把概率程序生成直接扩为首批全部要求。
3. **用独立数据检验区分能力。** 包含正常、不同原因的相似症状、缺失观测和不可区分情况，检查预测是否先于补充查询、结论是否有实际证据支持。
4. **形成瓶颈证据后再选扩展。** 候选模型不足时读 BMD；查询决策低效且奖励可计算时读 AR-BED；摘要遗漏信号信息时读 DiagLLM。复现前补查代码与数据许可、依赖、评价细节及成本。

本轮完成的是文献依据和研究设计调整。算法有效性、工作量和 HIL 迁移能力由后续实验记录回答。
