# 外部波形离线检查

本文供项目维护者与数据接收人员使用，说明如何检查当前收到的 tu1–tu4 两列 CSV、保存可复核结果，以及继续分析前需要确认的信息。

## 输入与运行

原始材料位于工作区上级 docs/tu/tu，各有同名 CSV 与示波器 PNG。CSV 无表头，两列按配对截图解释为时间（s）与电压（V）；测点、通道与探头倍率仍需提供方确认。当前脚本针对这四份文件及已读截图元信息，接收另一批数据时应重新确认格式和元信息映射。

在项目根目录，用环境配置中指定安装的配套 Python 执行：

```powershell
& 'D:\Typhoon\Typhoon HIL Control Center 2026.3\python3_portable\python.exe' -B -X utf8 scripts/analyze_external_waveforms.py --input-dir 'D:\Typhoon\docs\tu\tu' --output-dir 'results/填写新的波形检查目录'
```

输入目录必须包含 tu1.csv–tu4.csv 及各自同名 PNG；输出使用新目录。脚本检查列数、有限数值、严格递增时间和间隔均匀性，遇到缺失值、空行或不合规则停止。允许的时间间隔舍入误差为 max(1e-15 s, 中位间隔的 0.01%)。

## 输出与计算定义

| 文件 | 用途 |
|---|---|
| report.md、waveforms_full.png、waveforms_detail.png | 全程与局部图、数值描述、截图核对与待确认项 |
| profile.json | 每份输入的哈希、样本数、时间范围、统计量及元信息状态 |
| manifest.json | 输出文件哈希与输入 CSV 哈希；PNG 哈希保存在 profile.json |
| analysis_source.py | 本次执行脚本快照 |
| checks.ipynb | 只读复查原始 CSV 的简短代码；交付时未执行，不作为已通过证据 |

图表保留窗口内全部采样，不平滑、插值或跨文件对齐。tu1/tu2 以起始 10% 样本中位数为基准，描述低于基准 95% 的连续区段。tu3/tu4 以首尾各 10% 中位数定义低、高平台，记录首次向上穿越 10% 与 90% 的时间间隔，并计算该区间内从此前峰值到随后样本的最大回落。首次穿越间隔不能单独表示整个上升过程。

这些是描述性定义。控制器的验收阈值需要与测试负责人确定，数据标签及标签依据也需另行记录。

## 下一步接收信息

向提供方集中确认测量对象、测点、通道、单位、探头倍率、采集记录与导出设置、触发参考及正常/异常标签。截图采集速率、CSV 网格间隔和完整记录点数分别登记，避免把导出数据当作仪器全部原始采样。

离线分析可继续使用现有数据；回放任务需先确定关键幅值、边沿、持续时间及允许误差，再选择模型或仪器并记录转换方法。当前检查尚未接入仿真实验的 run/verify 记录协议，使用独立来源与文件清单，性能状态为 not_evaluated。

本批数据的实测数值和证据见[验证索引](validation-history.md)；水泵需求关联与接收责任见[专题记录](pump-hil-intake.md)。
