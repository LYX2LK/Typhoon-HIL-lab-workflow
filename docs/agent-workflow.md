# 用 Agent 提出实验任务与核对结果

本页介绍如何组织自然语言实验请求、检查返回结果。操作步骤见对应模型教程，模型扩展由维护者按 [接入方法](model-integration.md) 处理。

## 提出实验问题

在 Agent 中打开 `lab-workflow` 项目，说明要观察什么现象、改变什么条件、怎样评价结果。采用现有配置时给出配置名称；比较实验还需说明保持不变的条件。

| 请求中需要明确的内容 | 示例 |
|---|---|
| 实验对象与问题 | 比较 RLC 输入电阻变化后的电流与节点电压 |
| 配置与修改项 | 使用 rlc_sweep.json，Rin 取 1、5、10 Ω |
| 固定条件 | 其余条件沿用该配置 |
| 评价与交付 | 按配置判据核对，返回比较结论和原始数据路径 |

参数或指标不确定时，可以先请 Agent 结合现有模型提出方案，确认实验含义后再运行。环境准备见 [环境配置](environment.md)，参数与指标见 [RLC](experiments.md)、[Boost](boost-experiments.md) 或 [单相整流](rectifier-experiments.md)。

## 任务示例

### 查找与校验案例

> 列出项目现有案例，分别说明材料完整性、代码支持和真实运行证据。检查 im_speed_tracking 的配置与依赖，本次只做离线检查，不调用仿真 API。

### 比较电机转速跟踪

> 按感应电机案例运行 1430 rpm 和 850 rpm 两个独立启动工况。核对实际速度参考、负载指令和采样窗口，比较全窗口最大误差、超限点数及判据结论，返回真实目录并完成复核。

需要结构化工具返回时使用 [JSON 协议](case-interface.md)，支持子命令前后位置。`run-case --case im_speed_tracking --json` 会顺序执行已登记配置、实际复核并自动关联结果；其 record_status 来自复核。单份配置的 `run` 返回 record_status=null，须以实际 verify 结果交付记录一致性。

### 运行 RLC 基准

> 按 configs/rlc_baseline.json 运行基准实验，比较 I 与 Va1 的稳态 RMS 和解析参考。说明各项误差是否满足判据，给出报告、原始数据和复核结果。

### 比较 RLC 输入电阻

> 按 configs/rlc_sweep.json 比较 Rin 为 1、5、10 Ω 时的结果，其余条件保持不变。解释电流与节点电压 RMS 的变化，并给出各工况的实际数据。

### 比较 Boost 跟踪与抗扰动

> 按 Boost 教程运行基准、参考阶跃、输入跌落和输入升高四个工况。比较跟踪与恢复表现，列出每项判据的实际值和结论，解释未通过项。

### 比较单相整流工况

> 按单相整流教程运行基准、低输入与重载，并比较三条记录。解释直流电压、纹波和电流的变化，给出数值参考、实际数据与比较报告。

### 分析已有记录

> 分析这个实验目录：〈实际路径〉。核对数据与指标，解释结论及未通过原因，分别说明记录一致性与实验达标情况。本次只分析已有数据。

### 接入已有模型

> 将〈模型及依赖路径〉接入教学执行器。我希望研究〈实验问题与对照条件〉。请核实可改参数、测量信号和评价依据，补齐关键缺口后完成接入与实际 Virtual HIL 验证。

### 定位执行问题

> 执行命令是〈完整命令〉，结果目录是〈实际路径〉。请定位日志中的首次错误，修复后以相同配置重新运行，比较处理前后的结果。

## 接收结果时核对

| 要核对的问题 | 应能找到的证据 |
|---|---|
| 实际做了什么 | 采用的配置、修改项、固定条件和实际命令 |
| 波形来自哪里 | 原始 CSV、信号单位和时间范围 |
| 指标怎样得到 | 公式、窗口、归一化分母及预设判据 |
| 事件是否生效 | 实际参考或输入信号、检测区间和分辨率 |
| 比较是否完整 | 每个要求工况的状态、数值和报告路径 |
| 记录与性能怎样判定 | 最终复核结果、未通过判据及越限值 |
| 出错发生在哪一步 | 首次错误、失败阶段、清理结果和日志 |

每项任务应附可打开的任务记录和实际结果路径，便于将请求、命令与各次运行对应起来。文件位置与状态含义见 [结果核对](../README.md#核对结果)，任务记录格式见 [实现约定](../PROJECT_SPEC.md#agent-任务记录)。

解释应区分数据观察、理论依据和待验证机制。例如，某组 Rin 工况的 RMS 随电阻变化，需要对应这组数据；推广到其他频率或模型时需建立相应实验。需要独立复算时，可要求列出 CSV 样本数、公式和与原指标的差值。独立复现按 [交接流程](handoff.md) 记录。
