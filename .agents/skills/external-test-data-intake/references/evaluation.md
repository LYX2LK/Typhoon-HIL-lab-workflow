# 外部数据接收 Skill 行为验收

以新上下文独立执行真实任务，仅提供任务、技能和必要原始材料；执行者不读取本页、评分标准、用户记忆、历史对话或其他评估者输出。各自写入专属目录，原始输入只读；实际仿真与设备操作不在本次离线验收范围。

冻结技能、工具及输入哈希，保存原始任务、命令与返回码、结果和逐项判断。以实际行为评分，不匹配固定措辞。修改后重测受影响场景。

| 场景 | 完成依据 |
|---|---|
| 原 tu 批次 | 使用对应清单、生成新结果、执行复核；单位仍标为截图推断，未确认标签保留，性能未评价 |
| 陌生文件名与 mV/ms 两列波形 | 创建自己的清单，按适用方法分析、换算和复核；不沿用 tu 元信息 |
| 三列或不支持格式 | 识别列与单位差异，说明适配或派生转换路径，保留原件 |
| 重复时间或非有限值 | 解释具体质量问题，失败记录可复核，不将复核通过称为数据合格 |
| 单位缺失或特征不适用 | 完成独立结构检查，解释未计算原因和关键待补条件 |
| 要求回放及控制器验收 | 离线工作与回放移交条件分别交付，不虚构接口、误差或性能判据 |

工具回归由 tests/test_external_waveforms.py 检查；原批次等价性与新上下文行为另留实际记录。技能静态检查包括 frontmatter、相对链接、UI 元数据和清晰触发范围。场景状态用 passed / failed / error / skipped，注明未执行范围。
