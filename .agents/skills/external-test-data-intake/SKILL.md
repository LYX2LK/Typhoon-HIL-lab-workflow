# 外部测试数据接收与分析

## 选择任务路径

先明确数据要回答的问题，核对用户已确定的条件、材料可确认的事实和仍需选择的条件。已获授权的分析直接推进；影响物理含义的缺口集中澄清，同时继续可独立完成的结构检查。

- 外部文件的接收、离线分析和证据复核由本技能处理；仿真结果的实验解释、新案例与模型接入由 [实验工作流](../typhoon-lab-workflow/SKILL.md) 处理。
- 从外部数据转入实验时，移交数据清单、实际结果目录与复核、分析用途、已确认条件及待补条件。回放需明确注入位置、接口、幅值/时序误差和评价依据；收到波形本身不表示已完成回放。

## 将材料落实为数据清单

按 [输入与方法约定](../../../docs/external-waveforms.md) 检查实际列数、表头、时间轴和单位，填写来源及 confirmed / inferred / unconfirmed 状态。截图采集率、CSV 网格率与记录点数分别解释；配对关系和探头倍率保留依据。先查材料，再询问无法核实且会影响分析的条件。

选择 summary、dip 或 rise 及其窗口和参数，依据来自本次任务和波形含义。现有 tu 清单仅代表原批次事实；新文件使用自己的清单。三列、非均匀采样或未支持的单位先说明适配缺口，不通过改名、删列、插值覆盖原件来套用工具。任务需要转换时，保留原件，在派生副本记录转换方法后验证。

## 执行与核查

使用统一入口 `lab.ps1 analyze-waveforms --intake <清单> --input-dir <输入目录> --output-dir <新目录> --json`。格式、路径及退出码见方法约定；工具复制原始字节并生成来源、配置、方法快照、图表与报告。

用 `lab.ps1 verify-waveforms --run-dir <实际目录> --json` 独立复算；默认只读，本次新结果需要保存复核时加 `--write`。旧批次报告先读取；采用新方法重新分析时建立新结果，保留原记录。

分别解释数据质量、分析完成度、记录一致性和性能状态。结构检查失败或方法不适用也可以形成可复核记录；记录通过不等于数据适用。工具当前仅做描述性分析，performance_status 保持 not_evaluated；没有已确定判据时不输出控制器合格结论。

## 交付

先回答数据能否支持本次目的，再给出关键特征及单位、分析窗口、来源与未确认项、实际结果目录和复核结论。区分观察、计算和候选物理解释，说明下一步是继续离线分析、补材料还是移交实验。

修改技能时使用 [行为验收](references/evaluation.md)。批次结论查 [验证历史](../../../docs/validation-history.md)，水泵需求查 [专题记录](../../../docs/pump-hil-intake.md)。
