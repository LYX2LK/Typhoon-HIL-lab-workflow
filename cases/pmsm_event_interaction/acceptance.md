# PMSM 调速与负载事件交互：运行前方案

面向参与方法选型和样机接入的研究人员，比较事件顺序、间隔对软件闭环动态响应的影响。

- 使用现有等效星形 PMSM、理想角度与软件控制器；母线9 V，初始1800 rpm、0.01 N·m。调速至2400 rpm，加负载至0.03 N·m。其余参数继承软件预演。
- 10种独立配置：无事件、仅调速、仅负载、同时，以及两个顺序×5/20/100 ms。首个事件固定0.3 s。另重复仅调速和同时事件，共12次运行。
- 每次从相同模型初态启动，100 kSa/s记录0.8 s、7个信号、80000点。保持原始采样，不滤波、不插值。
- 采用显式event_group窗口：启动后0.1 s至首事件前；最后事件后0.1 s至记录结束。窗口最大绝对速度误差≤50 rpm，三相电流和绝对值≤0.01 A，事件电平和时间按现有预演规则核对。无事件对照评价0.1–0.8 s。阈值为沿用的软件探索判据，不是样机验收值。
- 两事件之间保留波形与动态指标，不要求在下一事件前已恢复。相同时间仅允许不同目标；不改变旧配置每段稳定评价。
- 派生主指标：以最后实际生效事件为零点，找最后一次超出±50 rpm后重新入带并保持至记录结束的时间；至少保留20 ms尾部证据。未恢复给null并标记截尾；限值100 ms，裕度=100 ms−恢复时间。
- 派生辅助指标：从首事件实际生效时刻起固定0.3 s窗口内最大绝对跟踪误差、误差绝对积分、最小速度、相电流峰值；最终事件后0.1–0.3 s的误差峰峰值仅描述剩余波动，不称振荡频率或阻尼。
- 各事件另记录首次变化前后的采样检测区间。正常基线确认启动影响；不同顺序比较描述总响应，不将差值直接解释为非线性交互。相同请求时刻以两条实际命令分别核验。
- n=每配置1次，仅调速与同时事件各2次。重复用于确定性复现检查，不做显著性、置信区间或总体故障概率推断。不将采样点数当独立样本。
- 运行错误或数据不足停止批次检查；真实性能失败保留并继续。用独立CSV计算核对核心指标；最终verify复核原记录。

执行：`.\lab.ps1 run-case --case pmsm_event_interaction --json`。
