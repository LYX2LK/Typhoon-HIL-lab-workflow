# 软件预演判据

本案例检查配置、模型、命令事件和采集流程。参数来源与假设以 configs/pmsm_software_preview.json 为准，不评价样机性能或模型对实物的准确度。

- 固定工况：模型母线 9V；1800rpm 启动，0.2s 改为 2400rpm，0.35s 负载从 0.01 增至 0.03Nm，0.55s 给零转速命令；记录至 0.8s。
- 采集：100kSa/s，预计 80000 点；机械速度、三相电流、电磁转矩、实际参考及负载命令。
- 每段变化后预留 0.1s，再对该段剩余完整样本评价，至少 1000 点。最大绝对转速误差不超过 50rpm。零速段使用绝对误差，不做零分母归一化。
- 实际参考和负载电平须匹配配置；事件时刻容差为 4×50μs 控制周期加 1 个采样周期，并报告首次变化样本。
- 最大 |Ia+Ib+Ic| 不超过 0.01A，仅用于三线电路一致性检查。
- 不平滑、滤波、插值或补齐原始样本。缺少事件、完整窗口或数据时停止评价并记录异常；性能超限保留 failed。

零转速命令由示例控制器主动调节，不代表样机停止、关断或后运行逻辑。模型使用内部角度反馈、等效星形参数和理想直流源；尚未建立单分流注入、样机无感算法和实体 I/O。
